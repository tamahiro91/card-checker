# card-checker

カードの所持状況をチェックする、無料の簡易ウェブアプリ（非公式ファンツール）。

https://tamahiro91.github.io/card-checker/

## 機能
- 各カードの「− / ＋」で所持枚数（ダブり含む）を記録、タップで 0 ⇔ 1 を切替
- 種類ごと・全体の所持数と進捗バー
- 「未所持／所持／ダブり」の絞り込み
- バックアップ（JSON 保存）と復元、リセット

## プライバシー
- アカウント登録・広告・アクセス解析はありません
- 記録はブラウザの localStorage にのみ保存され、外部へは送信されません
- 端末間の同期はありません。機種変更やブラウザのデータ削除に備えて「バックアップ」を使ってください
